# Biblioteca Clean - Arquitetura Cliente-Servidor (Exercício 8.3)

Este repositório contém a refatoração do sistema de biblioteca para uma Arquitetura Cliente-Servidor Desacoplada, utilizando uma API RESTful.

## 📁 Estrutura do Projeto
- **/backend**: Contém a Clean Architecture em Python (Domínio, Aplicação, Infraestrutura e Controladores REST).
- **/frontend**: Contém a interface em HTML, CSS e JavaScript Vanilla, totalmente isolada do servidor.

## 🚀 Como Executar o Projeto
